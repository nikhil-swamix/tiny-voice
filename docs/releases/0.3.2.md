# Tiny Voice 0.3.2

## Fixes

- **Simplified prompt.** The formatter prompt is now about 90 words with three guidelines instead of a long contract with examples.
- **Local schema fix.** The local profile uses a simpler recursive node schema; the cloud profile keeps the explicit three-level schema. This stops the small local model from over-generating while native validation still enforces three levels.
- **Distinct points, not one blob.** The prompt now requires 3–5 distinct points as short keys, one leaf per point, and explicitly forbids dumping the whole transcript under `message`. A single leaf is reserved for genuinely single-point speech.
- **Kept the structural repairs.** Up to three dynamic YAML levels, no fixed field list, single-child group flattening, duplicate-key merging, YAML scalar safety and the one-shot local recovery retry remain native. Local formatting now uses only the current transcript and vocabulary (no compact history or correction hints), and the local completion cap is 1,024 tokens so short dictation stays responsive.

## Pipeline and privacy

- Default remains local SGLang `minicpm5-2b-fp8`; GPT Transcribe remains off by default.
- The prompt is editable in Settings and saved as `formatting-prompt.txt`. The schema and repairs are not editable.
- No audio or transcript leaves the machine with the default local profile and GPT Transcribe off.

## Verification

- Native tests cover prompt validation, three-level rendering, four-level rejection, duplicate/single-child repair, YAML safety and custom instructions.
- The installed app was rebuilt and smoke-tested with a saved 20-second dictation on the local `minicpm5-2b-fp8` profile. It returned three grounded YAML fields in 1.28 s with no warning.
- A prior runaway case at the 8,192-token cap and with full history is removed: local formatting now sends only the current transcript/vocabulary and caps output at 1,024 tokens.
