# Tiny Voice 0.3.1

## Fixes

- **Dynamic YAML depth.** Output fields now support up to three mapping levels instead of two. The hierarchy is generated from the content; there is no fixed field list, and no `text` field is required.
- **Cleaner prompt examples.** The formatter prompt now shows the required JSON envelope and the visible YAML each example produces, so the local model is not trained to repeat JSON-shaped text in the result.
- **Local-model repair.** Redundant one-child groups are flattened, repeated keys are merged when their values are leaves, duplicate groups are merged, and shape conflicts receive a numeric key suffix. This repairs common MiniCPM5 repetitions such as `message: message: message: "..."` before rendering.
- **Stronger adherence guidelines.** The prompt now requires each phrase to appear once, forbids single-child groups and repeated keys at consecutive levels, and tells long continuous prose to stay as one leaf rather than becoming a nested hierarchy.
- **Group constraints.** The strict schema requires at least two children per group, while native normalization keeps a violating local response renderable instead of failing it.
- **Local retry for malformed JSON.** If the local model returns truncated or unrenderable JSON, Tiny Voice makes one single-leaf retry with a recovery prompt. The retry is recorded in the request audit. The local completion limit is raised to 8,192 tokens.

## Pipeline and privacy

- The default remains local SGLang `minicpm5-2b-fp8` at `http://127.0.0.1:30000/v1`.
- GPT Transcribe remains **off by default**; enable it in Settings to upload original audio.
- The formatter prompt remains editable in Settings and stored as `formatting-prompt.txt`. The YAML schema and native repairs are not editable.
- No audio, transcript or history is sent to OpenAI with the default local profile and GPT Transcribe off.

## Verification

- Native tests cover three-level rendering, four-level rejection, redundant-group flattening, duplicate-key merging, prompt validation, multiline YAML and custom instructions.
- The prompt was exercised against saved raw transcripts with the local MiniCPM5 model; results informed the anti-duplication and long-prose guidelines and the native normalization.
- Release build and NSIS installer were produced from this source.
- The installed app was rebuilt and relaunched with the new prompt and defaults.
