# Tiny Voice 0.2.0

## Changes

- Joined printer-style minibar/preview: equal width, zero gap, square preview top corners and a thin shared border.
- Content-driven growing/shrinking, responsive layout, scrolling and screen-relative limits.
- Default Turbo; Quick remains available. Older preferences migrate once; later selections persist.
- GPT-6.1 Sol with medium reasoning in both modes. Clean output targets up to 200 words and expands when needed.
- Fade applies once to the joined widget.
- Production Windows x64 installer, usage/model docs and SHA-256 checksums.

## Downloads

- `Tiny.Voice_0.2.0_x64-setup.exe`: per-user NSIS installer, WebView2 bootstrapper check.
- `Tiny.Voice_0.2.0_x64-portable.zip`: production executable and docs; requires WebView2 already installed.
- `SHA256SUMS.txt`: installer/archive hashes.

## Verification

JavaScript/Rust checks cover capture timing, microphone expiry/preemption, processing races, copy/paste, context, safe Markdown and formatting. Renderer checks verify the joined edges, Turbo default and dynamic sizing. Three synthetic live requests verified `gpt-6.1-sol` / `medium` response metadata; both short task outputs met the 200-word target. The installed package is checked for a visible, responsive native window and embedded UI.

## Requirements and limits

Windows 10/11 x64, microphone permission, internet, WebView2 and your own OpenAI API key with model access. The installer is unsigned. Audio/history are kept locally and sent to OpenAI as described in the [usage guide](https://github.com/nikhil-swamix/tiny-voice/blob/v0.2.0/docs/usage.md). Formatting does not execute tasks or do live research. Output length is adaptive, not hard-truncated.
